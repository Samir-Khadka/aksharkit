Text that looks the same can be stored in different ways, which breaks search. This gives one canonical form: repaired vowels, tidy spaces, । for a typed |.

Aksharas

Split text into aksharas, the written syllables of Devanagari: a consonant cluster with its vowel sign and marks stays in one piece (स्त्री is one, नमस्ते is three). Use it to count, or to shorten text without cutting a letter in half.

    Tokenise

    Split text into words and sentences. Nepali sentences end in ।, and a full stop inside डा. or रु. 99.50 must not end one.

        Sort

        Put a list in Nepali alphabetical order: vowels first, then क to ह, then क्ष, त्र, ज्ञ. A plain computer sort is close, but it files क्ष under क and ज्ञ under ज, puts ज़ after जह, and puts Nepali digits after every letter.

        Sorted

          Dictionaries differ on where anusvara and these conjuncts go. This order follows the rules written in the project's documentation; it is not claimed to match any particular dictionary. Empty lines are dropped.

          Detect script

          Which script is this text written in? Letters are sorted by their Unicode range into Devanagari, Latin, digits and other. This is not language detection: Nepali, Hindi, Marathi and Sanskrit all use Devanagari and look the same here.

            Preeti and Unicode

            A great deal of older Nepali text was typed in the Preeti font, where the file really holds Latin letters such as g]kfn that only look like नेपाल when that font is installed. Paste such text here, or open a text or Word file, to get real Unicode. The other direction turns Unicode back into Preeti keystrokes.

            Experimental. The key table is the part on which separately published, permissively-licensed tables agree. It has not yet been checked against real Preeti documents or by a native reader, so read the result before you rely on it. Keys with no agreed letter are left as they are, highlighted and listed below, never guessed.

            Unicode

            Web addresses and e-mail addresses in pasted text are left as they are. A Word file is different: only the text set in the Preeti font is converted, everything else in it is kept as it was, and the result is a new file to download. Nothing is guessed about which words are English.

            This page does not load the Preeti font. Have Preeti text with the correct Unicode beside it? That is what would turn this from experimental into checked: Preeti: help wanted (opens the project's issues page on GitHub).
